# The Magnet

An MRI system requires a magnet that is:

- Strong
- Highly homogeneous
- Stable

Modern 1.5T and 3.0T MRI systems use **actively shielded superconducting magnets**.

These magnets produce the static magnetic field **B₀**, which is essential for MRI.

---

# Basic Concepts

## Helmholtz Coil

A Helmholtz coil consists of:

- Two identical circular coils
- Coil separation equal to the coil radius (R)
- Equal current flowing through both coils in the same direction

Helmholtz coils create a relatively uniform magnetic field between the two windings.

# Field Strength

Like MRI magnets, Helmholtz coils are electromagnets.

Their magnetic field is generated by electrical current.

Near the center of the Helmholtz pair:

```text
B ≈ 0.7 μ₀ nI / R
```

where:

- B = magnetic field strength
- μ₀ = permeability of free space
- n = number of turns
- I = current
- R = coil radius
