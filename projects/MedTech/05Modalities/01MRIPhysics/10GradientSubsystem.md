# The Gradient Subsystem

The gradient subsystem generates the gradient magnetic fields used for spatial encoding in MRI.

These gradient fields are produced in response to waveform commands generated by the MRI system.

Without gradients:

```text
No Spatial Encoding
→ No Image Formation
```

The gradient subsystem is therefore one of the most important parts of the MRI scanner.

---

# Gradient Subsystem Overview

A typical gradient subsystem consists of five major components:

1. Controller
2. Gradient Amplifiers
3. Power Supply
4. Penwall Filter
5. Gradient Coil

- Controller
- Gradient Amplifiers

```text

```

The gradient subsystem is usually the largest electrical load in the MRI system.

The following components are water cooled:

- Gradient amplifiers
- Power supply
- Gradient coils

# Gradient Performance Parameters

The four most important gradient performance parameters are:

1. Gradient Strength (G)
2. Slew Rate (SR)
3. Gradient Field of View (FOV)
4. Duty Cycle

---

# Gradient Strength

Gradient strength describes how rapidly the magnetic field changes with position.

## Units

```text
G/cm
```

or

```text
mT/m
```

Conversion:

```text
1 G/cm = 10 mT/m
```

---

## Typical Values

Whole-body MRI:

```text
2 – 10 G/cm

20 – 100 mT/m
```

Extremity scanners:

```text
20 – 100 G/cm
```

---

## Definition

At isocenter:

```text
G = dB/dx
```

for x-gradient

```text
G = dB/dy
```

for y-gradient

```text
G = dB/dz
```

for z-gradient

---

## Why Strength Matters

Higher gradient strengths provide:

- Faster imaging
- Better spatial encoding
- Improved resolution
- Shorter scan times

---

# Gradient Slew Rate

Slew rate describes how quickly a gradient can change.

Definition:

```text
SR = dG/dt
```

Units:

```text
G/cm/ms
```

or

```text
T/m/s
```

Conversion:

```text
1 G/cm/ms = 10 T/m/s
```

---

## Typical Values

Whole-body MRI:

```text
5 – 20 G/cm/ms

50 – 200 T/m/s
```

---

## Why Slew Rate Matters

Higher slew rates allow:

- Faster switching
- Faster sequencing
- Reduced echo times
- Faster acquisition

---

# Gradient Field of View (FOV)

Gradient FOV defines the usable imaging region.

Typical values:

```text
35 – 50 cm
```

Generally:

```text
Gradient FOV
<
Magnet Bore Diameter
```

# Gradient Linearity

An ideal gradient field changes linearly with position.

Deviations from linearity create spatial distortion.

---

## Fig. 3-18: Gradient Linearity

```text
Field Strength B(x)

 ^
 |
 |                           Ideal
 |                          /
 |                         /
 |                        /
 |                       /
 |                      /
 |                     /
 |                ____/
 |           ____/
 |      ____/
 |_____/
 +----------------------------------> x

     Actual Gradient
```

Near isocenter:

```text
Actual ≈ Ideal
```

Far from isocenter:

```text
Actual < Ideal
```

---

## Why Linearity Matters

Since gradients determine position, gradient errors produce image errors.

### Consequences

- Object shifting
- Distortion
- Incorrect dimensions
- Geometric inaccuracies

# Gradwarp Correction

MRI systems compensate for gradient nonlinearities using:

```text
Gradwarp
```

Gradwarp intentionally applies the opposite distortion to restore geometric accuracy.

---

# Frequency Encoding

Because resonance frequency depends on magnetic field strength:

```text
f = γB
```

Adding a gradient makes frequency position dependent.

Without gradients:

```text
Position A → 63.86 MHz
Position B → 63.86 MHz
Position C → 63.86 MHz

No spatial information
```

With gradients:

```text
Position A → 63.5 MHz
Position B → 63.9 MHz
Position C → 64.2 MHz
```

---

## Frequency Mapping

```text
Frequency

64.2 MHz    ●
             \
63.9 MHz      ●
               \
63.5 MHz        ●

--------------------------------► Position
```

Different frequencies correspond to different spatial locations.

# Current and Voltage Waveforms

Gradient amplifiers are current-source amplifiers.

Typical performance:

### Current

```text
200 – 1000 A
```

### Voltage

```text
1200 – 2000 V
```

---

## Gradient Current Waveform

```text
Current

 ^
 |
 |        ┌───────────┐
 |       /             \

 |_____/                 \______
 |
 +--------------------------------→ Time
```

---

## Required Voltage Waveform

```text
Voltage

 ^
 |
 |    ┌─┐             ┌─┐
 |    │ │             │ │
 |____│ │_____________│ │_______
 |    │ │             │ │
 |    └─┘             └─┘
 |
 +--------------------------------→ Time
```

Voltage is highest during current ramps because:

```text
V(t) = Ri(t) + L di/dt
```

where:

- R = coil resistance
- L = coil inductance

# Gradient Driver

The gradient driver consists of:

```text
Controller
+
Amplifiers
+
Power Supply
```

---

# Controller

Functions:

- System communication
- Waveform download
- Waveform translation
- Eddy current compensation
- Gradient pre-emphasis
- Shim addition
- Feed-forward prediction

Converts logical gradients:

```text
Slice
Phase
Frequency
```

into physical gradients:

```text
Gx
Gy
Gz
```

---

# Amplifiers

The amplifiers generate:

- High current waveforms
- High voltage waveforms

Typical capability:

```text
200 – 1000 A

1200 – 2000 V
```

---

# Power Supply

The power supply:

- Converts AC to DC
- Supplies energy to amplifiers
- Supports rapid gradient switching

The gradient subsystem is often the largest power consumer in MRI.

---

# The Gradient Coil

The gradient coil converts current into magnetic fields.

Three independent coils generate:

```text
Gx
Gy
Gz
```

for spatial encoding along:

- x-axis
- y-axis
- z-axis

respectively.

---

# Key Takeaways

- The gradient subsystem creates the magnetic fields needed for spatial encoding.
- The subsystem consists of a controller, amplifiers, power supply, penwall filter, and gradient coil.
- The controller, amplifiers, and power supply together form the gradient driver.
- Gradient strength determines how rapidly magnetic field changes with position.
- Slew rate determines how fast gradients can change.
- Strong gradients and high slew rates enable faster imaging.
- Gradient FOV defines the usable imaging region.
- Gradient nonlinearity causes geometric distortion.
- Gradwarp compensates for gradient-induced distortion.
- Gradient amplifiers are current-source amplifiers.
- Typical gradient currents are 200–1000 A.
- Typical gradient voltages are 1200–2000 V.
- Gradient coils behave primarily as RL loads.
- Energy is both dissipated as heat and stored magnetically in the coil inductance.
- Three gradient coils (Gx, Gy, Gz) provide spatial encoding.
- Together with B₀ and B₁, the gradient subsystem enables MRI image formation.
